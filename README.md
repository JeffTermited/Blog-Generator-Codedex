# Pack&Go 旅行社網站

這是一個專業的旅行社網站，為Pack&Go旅行社提供完整的線上服務平台。

## 🚀 功能特色

### 前台功能
- ✅ 響應式設計，支援手機和電腦瀏覽
- ✅ 黑白主題設計，專業簡潔
- ✅ 首頁展示特色行程和優惠活動
- ✅ 詳細的服務介紹頁面
- ✅ 完整的行程列表展示
- ✅ 聯絡表單和公司資訊

### 後台管理功能
- ✅ 管理員登入系統
- ✅ 行程管理（新增、查看）
- ✅ 優惠活動管理（新增、查看）
- ✅ 即時統計資訊
- ✅ 安全的資料庫儲存

## 🛠 技術架構

- **後端框架**: Flask (Python)
- **資料庫**: SQLite
- **前端**: HTML5, CSS3, JavaScript
- **圖示**: Font Awesome
- **響應式設計**: CSS Grid & Flexbox

## 📦 安裝與設定

### 1. 安裝依賴套件

```bash
pip install -r requirements.txt
```

### 2. 執行應用程式

```bash
python app.py
```

### 3. 訪問網站

- 前台網站: http://127.0.0.1:5000
- 管理後台: http://127.0.0.1:5000/admin/login

## 🔧 自訂設定

### 修改公司資訊
在 `templates/` 目錄下的各個HTML文件中，您可以修改：
- 公司名稱和標誌
- 聯絡資訊
- 營業時間
- 地址和電話

### 新增行程
1. 登入管理後台
2. 點擊「新增行程」
3. 填寫行程資訊
4. 設定是否為特色行程

### 新增優惠
1. 登入管理後台
2. 點擊「新增優惠」
3. 填寫優惠資訊
4. 設定有效期和折扣

## 🚀 部署建議

### 生產環境部署
1. 使用 Gunicorn 或 uWSGI 作為WSGI伺服器
2. 設定 Nginx 作為反向代理
3. 使用 PostgreSQL 或 MySQL 替代 SQLite
4. 設定 SSL 憑證確保安全性

### 安全性建議
1. 修改預設管理員密碼
2. 設定強密碼政策
3. 定期備份資料庫
4. 監控系統日誌
